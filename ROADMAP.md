# everyLibC ROADMAP

This document describes the planned evolution of everyLibC across milestones.
Items are ordered by priority; no fixed dates are assigned.

---

## Milestone 1 MVP (current, complete)

- [x] Three-layer architecture: `core/` · `pal/` · `io/`
- [x] Linux PAL: x86-64 inline-syscall implementation + mmap-backed heap
- [x] `string.h` full memory and string primitive set
- [x] `ctype.h` ASCII character classification and conversion
- [x] `math.h` Newton-Raphson, Taylor-series math (no libm dependency)
- [x] `stdlib.h` string conversion, memory allocation wrappers, `qsort`, `bsearch`
- [x] `limits.h` `INT_MIN`/`INT_MAX`/`LONG_MIN`/`LONG_MAX`
  - [x] `stdio.h` `vsnprintf` / `printf` / `dprintf` / `snprintf` with full flag and width support
- [x] Meson build system with `platform` option
- [x] `_Noreturn` on `exit`, `abort`, `pal_exit`
- [x] `strtod` handles `"nan"` / `"inf"` / `"infinity"` (case-insensitive)
- [x] `floor`/`ceil` guarded against UB for `|x| ≥ 2^63`
- [x] `pow(negative, non-integer)` returns NaN per C standard

---

## Milestone 2 Unix-like PAL expansion

Extend PAL support to the major open-source Unix families.

- [x] **FreeBSD PAL** (`pal/freebsd/`) x86-64 syscall ABI; FreeBSD-specific
      mmap flags (`MAP_ANON`) and syscall numbers (`write`=4, `mmap`=197)
- [ ] **OpenBSD PAL** (`pal/openbsd/`) pledge/unveil awareness; separate
      mmap semantics
- [ ] **NetBSD PAL** (`pal/netbsd/`) NetBSD sysarch considerations
- [ ] **macOS PAL** (`pal/macos/`) Mach-O, libSystem interop, arm64 + x86-64
      dual-arch support via `_syscall` trampoline
- [ ] Architecture guard matrix: document which PAL supports which ISA
- [ ] Meson cross-compilation examples for each target

---

## Milestone 3 Windows PAL

- [ ] `pal/windows/` Win32 API via `WriteFile` / `ReadFile` / `VirtualAlloc` /
      `ExitProcess`; no CRT dependency
- [ ] PE/COFF build support in Meson (`windows_subsystem` option)

---

## Milestone 4 Core library growth

Expand the portable layer with more standard functions.

- [ ] `string.h` additions: `strtok`, `strdup`, `strndup`, `strerror`
- [ ] `math.h` additions: `atan`, `atan2`, `asin`, `acos`, `sinh`, `cosh`,
      `tanh`, `hypot`, `fmod`, `modf`, `frexp`, `ldexp`
- [ ] Payne-Hanek range reduction for `sin`/`cos`/`tan` (full-range accuracy)
- [ ] `stdlib.h` additions: `strtoul`, `strtoull`, `strtof`,
      `rand` / `srand` (xoshiro256** or similar)
- [ ] `time.h` stub: `time_t`, `clock_t`; PAL hook for wall-clock and
      monotonic time
- [ ] `assert.h`: `static_assert` wrapper + runtime `assert()` macro

---

## Milestone 5 Locale stub (`locale/`)

- [ ] Minimal `"C"` locale only, with extension points for future locales
- [ ] `strcoll`, `strxfrm`, `setlocale`, `localeconv` stubs
- [ ] Locale data stored in read-only arrays; no dynamic allocation required

---

## Milestone 6 Thread safety and atomic primitives

- [ ] `sync/` layer: thin wrappers over platform primitives
      (futex on Linux, critical section on Windows, pthreads mutex on POSIX)
- [ ] Atomic load/store/CAS for `uint32_t` and `uint64_t`
      using C11 `_Atomic` or compiler built-ins with an architecture fallback
- [ ] Thread-safe heap: spinlock-guarded free list in the PAL allocator
- [ ] Per-thread state hook in PAL for `errno`-like storage

---

## Milestone 7 Conformance test suite

- [ ] Self-contained test framework (`tests/framework/`) using only everyLibC symbols
- [ ] Per-function behaviour tests aligned with C11 Annex J and POSIX.1-2017
- [ ] Fuzz harness for `vsnprintf`, `strtod`, `strtol`
- [ ] CI integration (GitHub Actions) for Linux x86-64, macOS arm64, and a
      bare-metal QEMU target (Cortex-M3)

---

## Milestone 8 Packaging and tooling

- [x] `pkg-config` `.pc` file generated by Meson
- [x] `meson install` target: copies headers and `libelibc.a`
- [ ] CMake find-module (`FindElibc.cmake`) for projects not using Meson
- [ ] Optional compiler wrapper (`elibc-cc`) that sets `-I` / `-L` / `-ffreestanding`

---

## Milestone 9 Documentation

- [ ] Doxygen-compatible doc-comments on every public function
- [ ] Architecture Decision Records (`docs/adr/`) for key design choices
- [ ] Comparison table: everyLibC vs musl vs dietlibc vs newlib

---

*Items within a milestone are not ordered; priorities may shift based on
community feedback.*
